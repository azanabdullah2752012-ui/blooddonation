# 🩸 AVM Housing Society Mega Blood Donation Drive 2026

Official website for the **AVM Housing Society Annual Blood Donation Drive** scheduled for **Friday, 30th October 2026 at City Hall**.

Organised by the Managing Committee from the desk of **Sunil, Honorary Secretary**.

---

## 📅 Event Summary

- **Date:** Friday, October 30, 2026
- **Time:** 9:00 AM – 5:00 PM IST
- **Venue:** City Hall Ground Floor, AVM Housing Society Campus
- **In Association With:** Red Cross Blood Bank & City Healthcare Network
- **Goal:** 150 Donors (Impacting 450+ Lives)

---

## 🚀 Features

- **Live Countdown Timer:** Counts down directly to October 30, 2026, 9:00 AM IST.
- **Interactive Blood Compatibility Matrix:** Visual donor/recipient compatibility guide for all 8 blood groups (A±, B±, AB±, O±).
- **30-Second Eligibility Quiz:** Rapid 4-step wizard assessing age, weight, donation interval, and medical condition.
- **Donor Registration & Pass Generation:** Slot booking system with instant printable digital donor passes featuring simulated QR codes and pass IDs.
- **Resident Heroes Wall:** Dynamic pledge wall persisting resident registrations via `localStorage`.
- **Clinical Safety Protocols & FAQs:** Clear details on sterile single-use kits, physician monitoring, and recovery refreshments.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic, accessible markup with complete SEO tags.
- **Vanilla CSS:** Custom crimson and slate design system, glassmorphism, responsive grid layout, and dedicated print media styles.
- **JavaScript (ES6+):** Pure client-side state management, real-time calculation, and dynamic DOM rendering.

## 💻 Local Setup & Running

Simply open `index.html` in any web browser, or serve it using Python:

```bash
python3 -m http.server 8123
```

Then visit: [http://localhost:8123](http://localhost:8123)
